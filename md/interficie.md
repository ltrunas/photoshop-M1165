# Interfície de Photoshop: els menús

Guia de referència per saber on és cada cosa a Photoshop: què fa cada menú de la barra superior, amb els noms en castellà tal com apareixen al programa.

## Com llegir aquests apunts

A dalt de la pantalla hi ha la **barra de menú**, amb una paraula per cada grup d'ordres: Archivo, Edición, Imagen, Capa, Texto, Selección, Filtro, Vista, Ventana i Ayuda. Aquests apunts van menú per menú, de l'esquerra a la dreta, i expliquen les opcions que faràs servir al principi.

- **Dreceres:** les dono per a Windows. A Mac, Ctrl s'escriu Cmd i Alt s'escriu Opció.
- **Noms en castellà:** són els que surten al programa de l'aula. Segons la versió de Photoshop, alguna opció pot canviar de lloc o de nom; si no la trobes, usa el cercador del programa (la lupa de dalt a la dreta).
- **Menús que no cal obrir ara:** 3D (ja veurem si el fem servir; pot no aparèixer a les versions recents) i Plugins.

## Mapa dels menús

Cada menú és un mòdul independent d'aquests apunts: el trobaràs més avall amb el mateix nom i en l'ordre de la barra de menú.

| Menú | Per a què serveix | Quan el fem servir |
|---|---|---|
| **Archivo** | Crear, obrir, guardar, exportar i imprimir | Al començar i al acabar qualsevol feina |
| **Edición** | Desfer, Rellenar, transformar, Purgar, Ajustes de color, preferències | Constantment |
| **Imagen** | Mida, rotació, mode de color i ajustos de llum i color | En preparar o corregir una foto |
| **Capa** | Crear i organitzar capes, capes d'ajust, màscares | Sempre: és on treballem |
| **Texto** | Fonts i format del text | Quan afegim títols |
| **Selección** | Canviar la selecció i refinar vores de màscara | En retallar i retocar |
| **Filtro** | Difuminar, afegir soroll i altres efectes | En efectes i retoc |
| **Vista** | Zoom, regles i guies | Constantment |
| **Ventana** | Panells i espai de treball | Quan falta un panell o canviem de tasca |
| **Ayuda** | Ajuda oficial i cercador | Quan no trobem una opció |
| **Plugins i 3D** | Complements; 3D | De moment, no |


## On treballarem: Herramientas i Capas

Igual que a Illustrator, a Photoshop hi ha dues zones que faràs servir sempre. Els menús serveixen per consultar; aquestes dues són on es treballa.

- **Panell d'eines (Herramientas), a l'esquerra:** les eines que farem servir: Mover, Marco, Lazo, Recortar, Pincel, Borrador, Texto, Zoom, Mano… Les icones amb un triangle petit a la cantonada amaguen més eines: clic mantingut per veure-les. Quan tries una eina, la barra de opciones (sota el menú) canvia i mostra les seves opcions.
- **Panell Capas, a baix a la dreta:** és el més important. Hi ha totes les capes del document apilades: la de dalt es veu per sobre de les altres. Aquí és on anirem treballant: triar la capa activa, amagar-la amb l'ull, bloquejar-la amb el cadenat, canviar-ne l'ordre arrossegant-la i posar-li nom.

![Panell d'eines (Herramientas) de Photoshop](img/eines-toolbar.png)

**Abans de fer res, comprova quina capa està activa al panell Capas.** És l'error més comú de l'inici: pintes o mous una cosa a la capa equivocada.

A dalt del panell Capas hi ha el **Modo de fusión** i l'**Opacidad**. A la part de baix, una fila de botons per a les accions més usades, d'esquerra a dreta:

| Botó | Què fa |
|---|---|
| Vincular capas | Vincula capes perquè es moguin juntes |
| Estilos de capa (fx) | Afegeix efectes com sombra o traç |
| Añadir máscara de capa | Crea una màscara a la capa activa |
| Crear nueva capa de relleno o ajuste | Afegeix una capa d'ajust de llum o color |
| Crear grupo nuevo | Crea una carpeta de capes |
| Crear capa nueva | Afegeix una capa buida |
| Eliminar capa | Esborra la capa activa (la paperera) |


Si el panell Capas no es veu, obre'l amb **Ventana > Capas** (F7). L'ordre dels botons i la posició dels panells poden canviar una mica segons la versió i l'espai de treball.

## Espacio de trabajo: adapta Photoshop a la tasca

Un espai de treball és una combinació de panells guardada, amb la seva posició a la pantalla. No cal treballar sempre amb el mateix: el més útil és triar o crear el que s'adapti al que estem fent en cada moment.

A dalt a la dreta, a la barra d'opcions, hi ha la icona de l'espai de treball: és un accés ràpid per canviar-lo.

![Icona de l'espai de treball, a dalt a la dreta](img/espacio-trabajo-icona.png)

- **Triar un espai ja preparat:** Ventana > Espacio de trabajo. Photoshop en porta de preparats, com Fundamentos (o el nom equivalent a la teva versió), Fotografía, Pintura, Gráficos y web i Movimiento.
- **Quin triar:** Fundamentos per començar. Fotografía quan fem retoc de pell i color. Pintura quan treballem amb pinzells.
- **Crear el teu:** col·loca els panells on et convingui (arrossega la pestanya d'un panell) i tanca els que no facis servir. Després, Ventana > Espacio de trabajo > Nuevo espacio de trabajo i posa-li un nom.
- **Tornar a l'inici:** si ho has desquadrat tot, Ventana > Espacio de trabajo > Restablecer, seguit del nom de l'espai actual.

El panell **Capas** és l'únic que vols tenir sempre visible, sigui quin sigui l'espai que triïs.

### Crear un document (Archivo > Nuevo)

La finestra demana quatre coses:

- **Anchura i Altura:** la mida, amb la unitat que triis (píxels per a pantalla, mil·límetres o centímetres per a paper).
- **Resolución:** 72 píxels/pulgada (ppp) per a pantalla i 300 per a impressió.
- **Modo de color:** RGB per a pantalla i CMYK per a impressió.
- **Contenido de fondo:** blanc, un color o transparent.

### Guardar o exportar?

Són dues coses diferents. **Guardar** conserva el teu treball editable: el format PSD guarda les capes i tot el que has fet. **Exportar** crea una còpia final en un format lleuger per enviar o publicar, però ja no es pot editar com abans.

- Guarda sempre un **PSD** abans d'acabar. Un JPG no guarda les capes.
- **Archivo > Exportar > Exportación rápida como PNG:** treu un PNG amb un sol clic.
- **Archivo > Exportar > Exportar como** (Alt + Maj + Ctrl + W): tria format (JPG o PNG), qualitat i mida abans d'exportar. És la manera més còmoda de fer un JPG per a xarxes.
- **Archivo > Exportar > Guardar para web (heredado):** una versió antiga amb el mateix objectiu. A les versions recents ja no cal.

### Imprimir (Archivo > Imprimir)

La finestra mostra una vista prèvia del full i deixa triar la impressora, el nombre de còpies, l'orientació del paper, la posició de la imatge al full i l'escala. També hi ha la gestió del color: tria si el color el controla Photoshop o la impressora. Si imprimeixes en paper, treballa a 300 ppp i en CMYK o segons el que demani la impremta. Per fer un PDF per imprimir, usa Guardar como i tria Photoshop PDF.

### Rellenar: per a què serveix

Omple d'un color o d'un contingut la selecció que has fet. Si no hi ha cap selecció, omple tota la capa activa. La finestra té tres parts:

- **Contenido:** amb què s'omple. Color de primer plano, Color de fondo, Color (que obre el selector), Según el contenido (inventa el que hi ha al voltant, útil per esborrar un objecte), Motivo (un patró), Historia, Negro, 50 % de gris i Blanco.
- **Modo:** com es barreja amb el que ja hi ha. Normal omple directament.
- **Opacidad:** com de fort es veu l'omplert.

Dues dreceres que estalvien temps: **Alt + Retrocés** omple amb el color de primer pla i **Ctrl + Retrocés** amb el color de fons.

### Purgar: per a què serveix

Photoshop guarda a la memòria els passos que has fet (Historial), el que has copiat (Portapapeles) i altres dades temporals. Purgar esborra aquesta memòria per alliberar espai quan el programa va lent. Les opcions són Deshacer, Portapapeles, Historia i Todo. **No es pot desfer:** un cop purgat, no pots tornar enrere amb Ctrl + Z.

### Ajustes de color: no és corregir una foto

Aquest menú **no** serveix per canviar els colors d'una imatge. Defineix com Photoshop interpreta i mostra el color (per exemple, quin espai RGB i quin CMYK fa servir). De moment, deixa-ho tal com està. Per canviar el color d'una foto, usa **Imagen > Ajustes** (vegeu el menú Imagen).

## Imagen: mida, color i ajustos

Aquest menú canvia la imatge sencera: la mida, el mode de color i la correcció de llum i color.

| Opció | Drecera | Què fa |
|---|---|---|
| **Modo** |  | Canvia el mode de color del document: RGB per a pantalla, CMYK per a impressió, Escala de grises. També la profunditat (8, 16 o 32 bits per canal) |
| **Ajustes** |  | Corregeix llum i color (vegeu més avall) |
| Autotono, Autocontraste, Autocolor | Maj + Ctrl + L, Alt + Maj + Ctrl + L, Maj + Ctrl + B | Correccions automàtiques ràpides |
| **Tamaño de la imagen** | Alt + Ctrl + I | Canvia les dimensions i la resolució de **la imatge** |
| **Tamaño de lienzo** | Alt + Ctrl + C | Canvia la mida de **la taula de treball**, sense escalar la imatge |
| Rotación del lienzo |  | Gira tot el document: 90°, 180° o un angle lliure |
| Recortar |  | Retalla la imatge segons una selecció |
| Duplicar |  | Fa una còpia del document |


### Canviar la mida: imatge o lienzo?

La pregunta més freqüent. Els dos canvien la mida, però de manera molt diferent.

|  | Tamaño de la imagen | Tamaño de lienzo |
|---|---|---|
| Què canvia | La imatge s'ampliarà o es reduirà amb el document | Només l'espai de treball; la imatge es queda igual |
| Efecte | Escala la imatge (es pot perdre qualitat si l'amplies) | Si l'amplies, afegeix espai buit al voltant; si el redueixes, talla la imatge |
| Quan | Per canviar mida o resolució d'una foto | Per afegir un marge o canviar les proporcions del document |
| On es tria | Anchura, Altura, Resolución i la casella Remuestrear | Anchura, Altura i un punt d'ancoratge que indica per quin costat creix |


A Tamaño de lienzo, marca **Relativo** si vols dir quant creix (per exemple, 100 píxels més) i no la mida final. El punt d'ancoratge decideix per quin costat s'afegeix l'espai.

### Ajustes: llum i color (inclou Niveles)

Aquí hi ha les ordres per corregir una foto. Les més útils per començar:

- **Niveles** (Ctrl + L): mostra un histograma amb tres cursors per ajustar ombres (negres), tons mitjos (grisos) i llums (blancs).
- **Curvas** (Ctrl + M): control més fi del contrast i la llum.
- **Brillo/contraste:** el més senzill, però menys precis.
- **Tono/saturación** (Ctrl + U): canvia el color, la intensitat o la claredat.
- **Equilibrio de color** (Ctrl + B): afegeix o treu tonalitats a ombres, mitjos i llums.
- **Blanco y negro**, **Desaturar** (Maj + Ctrl + U) i **Invertir** (Ctrl + I).

**Compte:** si apliques un ajuste des d'aquí, modifiques els píxels de la capa i no es pot revisar més tard. Després veuràs una manera millor, les capes d'ajuste, al menú Capa.

Si en comptes de la mida del document busques les **mesas de trabajo** (diverses àrees dins d'un mateix fitxer), no són aquí: es creen des del menú Capa.

## Capa: el cor de Photoshop

![Menú Capa](img/menu-capa.png)

| Opció | Drecera | Què fa |
|---|---|---|

| Nuevo > Capa vía cortar | Maj + Ctrl + J | Igual, però treu la selecció de la capa original |
| Nuevo > Grupo |  | Crea una carpeta per agrupar capes |
| Duplicar capa / Eliminar |  | Copia o esborra la capa activa |
| **Estilo de capa** |  | Efectes no destructius: Sombra paralela, Resplandor exterior, Trazo, Superposición de color o de degradado |
| **Nueva capa de ajuste** |  | Afegeix un ajust de llum o color en una capa a part (vegeu més avall) |
| Nueva capa de relleno |  | Una capa amb color pla, degradat o motiu |
| **Máscara de capa** |  | Amaga o mostra parts d'una capa sense esborrar res |
| **Crear máscara de recorte** | Alt + Ctrl + G | Fa que una capa només es vegi dins de la forma de la capa de sota, com la màscara de retall d'Illustrator |
| **Objetos inteligentes** |  | Converteix una capa en un objecte que es pot escalar i editar sense perdre qualitat |
| Rasterizar |  | Converteix text, formes o objectes intel·ligents en píxels normals. Ja no es poden editar com abans |

| Organizar |  | Ordre de la capa: Traer al frente, Traer adelante, Enviar atrás, Enviar al fondo |
| Alinear / Distribuir |  | Alinea o reparteix capes entre elles o respecte la selecció |

| Acoplar imagen |  | Fusiona totes les capes en una. Compte: perds l'edició |


### Capes d'ajust: la manera correcta de corregir color

A Imagen > Ajustes modifiques els píxels directament. Una **capa d'ajust** (Capa > Nueva capa de ajuste > Niveles, Curvas, Tono/saturación…) aplica el mateix efecte a **una capa a part**. Pots canviar-lo, amagar-lo o esborrar-lo quan vulguis i la foto original queda intacta.

### Màscares: amagar sense esborrar

Una màscara de capa funciona amb blanc i negre: el **blanc mostra**, el **negre amaga** i els grisos amaguen una part. Pintant amb el Pincel sobre la màscara, amagues o recuperes zones. A diferència del Borrador, sempre pots corregir-ho. Opcions: Mostrar todo (màscara blanca), Ocultar todo (negra), Mostrar selección i Ocultar selección.

### Objecte intel·ligent

Si redueixes una imatge normal i després l'amplies, perds qualitat. Si la converteixes abans en objecte intel·ligent (Capa > Objetos inteligentes > Convertir en objeto inteligente), Photoshop recorda l'original i no perd detall en escalar-la.

## Vista

![Menú Vista](img/menu-vista.png)

Canvia **com mires** el document, sense modificar la imatge.

| Opció | Drecera | Què fa |
|---|---|---|
| Ampliar / Reducir | Ctrl + + / Ctrl + – | Zoom més o menys |
| **Ajustar en pantalla** | Ctrl + 0 | Fa que el document s'ajusti a la finestra. Recomanat: clícal sempre que obris un document |
| **100 %** | Ctrl + 1 | Mostra la imatge a mida real, per revisar detalls |
| **Reglas** | Ctrl + R | Mostra regles als marges. Des d'allà s'arrosseguen guíes |
| Mostrar |  | Activa o amaga Guías, Cuadrícula i altres ajudes visuals |
| Ajustar | Maj + Ctrl + ; | Fa que les capes i les eines s'enganxin a guíes o a la quadrícula |
| Extras | Ctrl + H | Amaga o mostra de cop les ajudes visuals |


**Guías:** són línies d'ajuda per alinear elements. Primer s'activen les **regles** amb **Ctrl + R** (Cmd + R a Mac). Després, des d'una regla s'arrossega una guía cap al document, o es crea amb Vista > Guías > Nueva guía. Per amagar-les o tornar-les a mostrar, Vista > Mostrar > Guías (Ctrl + ; o Ctrl + H, Cmd + ; o Cmd + H a Mac). Les guíes no s'imprimeixen ni s'exporten. Per eliminar-ne una, selecciona-la i prem Suprimir (Borrar). Per eliminar-les totes, Vista > Guías > Borrar guías.

**Modo de pantalla:** la tecla **F** canvia entre els modes de pantalla: l'estàndard, la pantalla completa amb barra de menú i la pantalla completa sense res més que la imatge. Serveix per veure la peça sense distraccions; torna a prémer F fins al mode estàndard (o Esc). Només funciona si no estàs escrivint amb l'eina Texto. També es tria a Vista > Modo de pantalla.

## Ventana

![Menú Ventana](img/menu-ventana.png)

Aquí es controla què es veu a la pantalla: panells i espai de treball.

| Opció o panell | Drecera | Per a què serveix |
|---|---|---|
| **Espacio de trabajo** |  | Tria o desa la distribució de panells (vegeu el mòdul Espacio de trabajo) |
| **Capas** | F7 | Les capes del document. El més important |
| Propiedades |  | Opcions de la capa o de l'objecte que tens triat |
| Historial |  | Llista de passos fets, per tornar enrere |
| Ajustes |  | Capes d'ajust de llum i color |
| Color | F6 | Triar el color de primer pla i de fons |
| Muestras |  | Colors preparats per triar |
| Pinceles | F5 | Opcions del pinzell |
| Carácter, Párrafo |  | Format del text |
| Información | F8 | Dades del píxel sota el cursor |
| Herramientas, Opciones |  | Mostren o amaguen la barra d'eines i la barra d'opcions, si les has amagat sense voler |


Els panells que no estan oberts queden replegats com a icones en una columna al costat dels panells oberts (a la imatge, Histograma i Navegador). Clica una icona per obrir-ne el panell.

![Panells replegats com a icones, al costat de Histograma i Navegador](img/panells-icones.png)

**Activar i desactivar panells:** des de Ventana pots mostrar o amagar els panells segons el que estiguem fent. Activa només el que necessitis, com **Línea de tiempo** (animació i vídeo) o **Muestras** (colors preparats), i desactiva'l quan acabis. Així la pantalla queda neta i el panell Capas té més espai.
